## 게임 실행

Windows 10 이상이 필요합니다. 게임 실행에는 Python이나 Blitz3D 설치가 필요하지 않습니다.

| 받은 파일 | 실행 방법 |
| --- | --- |
| 배포 ZIP | 전체 압축을 풀고 안쪽 게임 폴더의 `Play.cmd` 실행 |
| 소스 저장소 — 기본판 | [최초 빌드](development-ko.md#최초-빌드) 후 저장소 루트의 `Play.cmd` 실행 |
| 소스 저장소 — 확장판 | [확장판 준비](development-ko.md#기본판과-확장판) 후 저장소 루트의 `Play-Extended.cmd` 실행 |

기본판 이름은 기존 **Stranded II**를 유지합니다. `Classic`은 개발용 구분이며 창 제목이나 실행 파일명에 붙이지 않습니다. 확장판 창 제목은 **Stranded II - Extended**입니다.

아래 **게임 폴더**는 기본판의 `StrandedII.exe` 또는 확장판의 `StrandedII-Extended.exe`가 있는 곳입니다. 소스 저장소에서는 기본판 `build/runtime/`, 확장판 `build/extended/runtime/`입니다. 두 판의 설정과 세이브는 별개이며 자동 가져오기는 제공하지 않습니다.

## 화면·프레임·언어 바꾸기

1. **설정 → 그래픽**을 엽니다.
2. 해상도, 화면 모드, FPS 또는 언어를 선택합니다. 선택 칸의 왼쪽 클릭은 다음 값, 오른쪽 클릭은 이전 값입니다.
3. **적용**을 누르고 게임을 종료한 뒤 다시 실행합니다. **취소**하면 변경 내용을 저장하지 않습니다.

| 항목 | 선택과 기본값 |
| --- | --- |
| FPS | 60 / 120 / **144(기본값)**. 실제 FPS는 PC와 장면에 따라 달라집니다. |
| 화면 모드 | 일반 창 / **전체 창(기본값, 테두리 없음)** |
| 해상도 | **모니터에 맞춤(기본값)** 또는 지정한 크기 |
| 언어 | **영어(기본값)** / 한국어 / 추가한 언어팩 |

기존 설치는 저장된 설정을 유지합니다. **모니터에 맞춤**은 주 모니터를 기준으로 하며, 렌더링 크기는 최소 800×600, 각 변 최대 2048픽셀로 보정합니다. 2560×1440·3840×2160 모니터에서는 2048×1152로 그린 뒤 전체 창 크기로 확대합니다. 해상도 선택 칸은 실제 렌더링 크기를 표시합니다.

언어 전환은 실험 기능입니다. 빠진 번역이나 설치되지 않은 언어는 영어로 표시합니다. 기존 세이브에 문장 그대로 기록된 한국어는 언어를 바꿔도 남을 수 있습니다. 번역을 고치거나 언어를 추가하려면 [현지화 가이드](localization-ko.md)를 참고하세요.

## 그래픽 품질과 소리

게임의 설정 메뉴에서 바꿉니다. 새 설치는 시야 거리·지형·물·하늘·효과·풀을 최고 단계로 시작합니다. 2D 효과·빛 효과·바람에 따른 움직임·안개·하드웨어 멀티텍스처는 켜짐, 모션블러는 켜짐·35%, 배경음과 효과음은 각각 50%입니다.

기존 `mods/Stranded II/sys/settings.cfg`가 있으면 저장된 값을 유지합니다.

## 저장 파일과 백업

저장 위치는 **게임 폴더의 `mods/Stranded II/saves/`**입니다. 다른 PC로 옮기거나 게임 폴더를 정리하기 전에 이 폴더를 백업하세요. 직접 만든 지도·스크린샷과 `preserved/` 폴더가 있다면 함께 보관합니다.

| 기능 | 동작 |
| --- | --- |
| 계속하기 | 수동·빠른·자동 저장 중 정상적인 헤더·끝 표식을 가진 가장 최근 수정 파일을 불러옵니다. 파일이 없으면 비활성화됩니다. |
| 빠른 저장/불러오기 | 설정 → 조작에 지정된 키를 사용합니다. 파일은 `QUICKSAVE.sav`입니다. |
| 자동 저장 | `AUTOSAVE.sav`, `AUTOSAVE_2.sav`~`AUTOSAVE_5.sav`의 5개 슬롯을 채운 뒤 가장 오래된 슬롯을 교체합니다. 저장 주기는 원작과 같습니다. 자동 불러오기는 가장 최근 슬롯을 사용합니다. |
| 이전 저장본 백업 | 덮어쓰기 직전 파일을 `.sav.bak`으로 보관합니다. 백업은 저장 목록에 표시하지 않습니다. |

백업을 복구하려면 게임을 종료하고 `QUICKSAVE.sav.bak` 등을 **`recovered.sav`라는 새 이름으로 복사**한 뒤 불러오세요. 기존 저장을 시험할 때도 복사본을 사용하고 별도 이름으로 저장합니다.

저장 중 오류가 나면 기존 파일을 유지하고 오류를 표시합니다. 파일 헤더와 끝 표식 검사가 모든 손상을 찾아내는 것은 아닙니다. 개발용 `build/`에도 실제 세이브가 있으므로 통째로 지우기 전에 백업하세요.

## 설정 파일과 실행 옵션

메뉴 대신 파일을 수정하려면 게임을 종료하고 **게임 폴더의 `core/modern.ini`**를 엽니다.

```ini
language=en
fps=144
display=borderless
resolution=desktop
render_width=1280
render_height=720
diagnostics=0
```

| 항목 | 값 |
| --- | --- |
| `language` | `en`, `ko` 또는 설치된 언어 코드 |
| `fps` | `60`, `120`, `144` |
| `display` | `borderless`(전체 창), `windowed`(일반 창) |
| `resolution` | `desktop`(모니터에 맞춤), `custom`(아래 크기 사용). 항목이 없는 옛 설정은 `custom` |
| `render_width`, `render_height` | `custom`의 렌더링 크기. 최소 800×600, 각 변 최대 2048픽셀 |
| `diagnostics` | `1`이면 `core/modern.log`에 프레임·화면 복귀 기록 저장 |

실행 옵션은 파일 설정보다 우선합니다. PowerShell에서 게임을 실행할 때 지정하세요. 확장판 소스 저장소에서는 `Play-Extended.cmd`를 사용합니다.

```powershell
.\Play.cmd -fps 120
.\Play.cmd -win -fps 60
.\Play.cmd -borderless
```

`config/modern.ini`와 `config/editions/extended/modern.ini`는 개발용 초기값입니다. 이미 준비한 게임의 설정은 위의 `core/modern.ini`에서 바꾸세요.

끊김이나 외부 배속 복귀를 점검할 때는 `diagnostics=1`로 기록한 `FPS actual`을 참고할 수 있습니다. 이는 게임의 화면 표시 호출 빈도이며 모니터 주사율은 아닙니다. 프레임당 게임 시간 증가를 100ms로 제한하므로 부하가 큰 장면에서는 실제 배속이 설정값보다 낮을 수 있습니다.

# 실행 및 설정

## 게임 실행

Windows 10 이상에서 저장소 루트의 `Play.cmd`를 실행합니다. 실제 실행 파일은 `build/runtime/StrandedII.exe`입니다. 게임 실행에는 Python이 필요하지 않습니다.

소스 저장소에는 실행 파일과 원본 게임 리소스가 포함돼 있지 않습니다. 처음 준비하는 경우 [개발 가이드](development-ko.md)의 환경 구성과 빌드를 먼저 진행하세요.

## 프레임과 화면 모드

**설정 → 그래픽**에서 해상도, 창/전체 창 모드, 60/120/144 FPS를 선택할 수 있습니다. 선택 칸을 왼쪽 클릭하면 다음 값, 오른쪽 클릭하면 이전 값으로 바뀝니다. **적용** 후 게임을 종료하고 다시 실행하면 반영됩니다. **취소**하면 이번 선택을 저장하지 않습니다.

새 설치의 기본값은 **144 FPS, 전체 창 모드, 모니터에 맞춤**입니다. 기존 설치의 설정은 보존하므로 이전 1280×720 설정도 그대로 유지됩니다. FPS는 목표값이며 실제 프레임은 PC 성능과 화면 환경에 따라 달라집니다.

**모니터에 맞춤**은 Windows 주 모니터를 기준으로 렌더링 크기를 계산합니다. 현재 Direct3D 경로에서 큰 렌더링 해상도의 초기화 실패를 피하려고 각 변을 최대 **2048픽셀**로 제한합니다. 예를 들어 2560×1440과 3840×2160 모니터에서는 2048×1152로 렌더링하고 전체 창 모드에서 모니터 크기로 확대합니다. 선택 칸의 숫자는 실제 렌더링 크기입니다. 매우 넓거나 세로로 긴 화면에서는 기존 UI의 최소 크기인 800×600도 적용됩니다.

PowerShell에서 실행 옵션으로 바꿀 수 있습니다.

```powershell
.\Play.cmd -fps 144
.\Play.cmd -fps 120
.\Play.cmd -win -fps 60
.\Play.cmd -borderless
```

계속 사용할 설정은 게임을 종료한 뒤 `build/runtime/core/modern.ini`에서 수정합니다.

```ini
language=en
fps=144
display=borderless
resolution=desktop
render_width=1280
render_height=720
diagnostics=0
```

| 항목 | 설정 |
| --- | --- |
| `fps` | `60`, `120`, `144` |
| `display` | `borderless`: 전체 창 모드, `windowed`: 일반 창 모드 |
| `resolution` | `desktop`: 주 모니터에 맞춤, `custom`: 아래 해상도 사용. 항목이 없는 기존 설정은 `custom` |
| `render_width`, `render_height` | `custom`일 때 내부 렌더링 해상도. 최소 800×600, 각 변 최대 2048픽셀로 보정 |
| `language` | `ko`: 한국어, `en`: 영어 또는 설치된 언어팩의 코드 |
| `diagnostics` | `1`이면 `core/modern.log`에 프레임과 화면 복귀 기록 저장 |

실행 옵션 `-fps`, `-win`, `-borderless`는 위 파일의 설정보다 우선합니다. 저장소의 `config/modern.ini`는 처음 실행 폴더를 만들 때 사용하는 기본값입니다. 이미 준비된 게임의 설정은 `build/runtime/core/modern.ini`에서 바꿉니다.

## 테스트 중 배속 변경

게임 진행 시간과 프레임 대기 시간을 분리했습니다. 게임 시간은 배속이 반영되는 고해상도 시계를, 프레임 제한은 별도의 실제 시간 시계와 Windows 대기 함수를 사용합니다. Cheat Engine이 1배속으로 돌아온 뒤에도 저해상도 시계 변경을 유지해 생기던 움직임·프레임 대기의 끊김을 방지합니다. 과도한 시뮬레이션 증가를 막는 프레임당 100ms 제한은 유지하므로 부하가 큰 장면의 실제 배속은 설정값보다 낮을 수 있습니다.

배속 복귀 후 부드러움이 달라지면 `diagnostics=1`로 실행해 `core/modern.log`의 `FPS actual` 기록을 확인할 수 있습니다. 이 값은 게임의 프레임 표시 호출 빈도이며 모니터의 물리적 주사율과는 다릅니다.

## 언어 변경

**설정 → 그래픽 → 언어**에서 해상도와 같은 선택 칸을 사용합니다. 왼쪽 클릭은 다음 언어, 오른쪽 클릭은 이전 언어입니다. 적용한 뒤 게임을 종료하고 다시 실행합니다. 취소하면 선택한 언어를 저장하지 않습니다. 기본 언어는 영어입니다.

기본 제공 번역은 한국어·영어이며 언어팩을 추가하면 선택 목록에 나타납니다. 빠진 번역은 영어로 표시하고, 설치되지 않은 언어가 설정돼 있으면 영어로 시작합니다. 새 언어는 [현지화 가이드](localization-ko.md), 언어별 폰트 지정은 [폰트 가이드](fonts-ko.md)를 참고하세요. 언어 전환은 현재 실험 기능입니다.

## 그래픽 품질과 소리

새 설치에서는 시야 거리, 지형, 물, 하늘, 효과, 풀을 모두 최고 단계로 시작합니다. 2D 효과, 빛 효과, 바람에 따른 움직임, 안개, 하드웨어 멀티텍스처도 켜집니다. 모션블러는 기존 기본값인 켜짐, 강도 35%를 유지합니다. 배경음과 효과음은 각각 50%입니다.

기존 `mods/Stranded II/sys/settings.cfg`가 있으면 저장된 그래픽 품질과 음량을 그대로 사용합니다. 배포 ZIP에는 개인 설정 파일을 포함하지 않으며, 파일이 없는 새 설치는 엔진의 초기값을 사용합니다. 그래픽 품질과 소리는 게임의 설정 메뉴에서 바꿀 수 있습니다.

## 저장 파일

저장 위치는 `build/runtime/mods/Stranded II/saves/`입니다. 다른 PC로 옮기거나 실행 폴더를 초기화하기 전에 이 폴더를 백업하세요. 직접 만든 지도와 스크린샷도 함께 보관합니다.

- **계속하기:** 메인 메뉴에서 정상적인 헤더·끝 표식을 갖춘 `.sav` 중 수정 시각이 가장 최근인 파일을 엽니다. 수동·빠른·자동 저장을 모두 포함합니다. 해당 파일이 없으면 버튼이 비활성화됩니다.
- **빠른 저장/불러오기:** 설정 → 조작에서 지정한 키를 사용합니다. `QUICKSAVE.sav` 한 개를 사용하며, 저장 파일이 없으면 안내를 표시합니다.
- **자동 저장 5개:** 기존 자동 저장 시점에 `AUTOSAVE.sav`, `AUTOSAVE_2.sav`부터 `AUTOSAVE_5.sav`까지 채운 뒤 가장 오래된 슬롯을 교체합니다. 자동 저장 주기 자체는 바꾸지 않았습니다. 자동 불러오기는 이 다섯 개 중 가장 최근 저장을 선택합니다.
- **이전 저장본 백업:** 먼저 같은 폴더의 `.tmp`에 기록하고 파일을 교체합니다. 덮어쓰는 파일의 직전 내용은 `.sav.bak`으로 보관합니다. 백업은 저장 목록의 5개 자동 슬롯과 별도이며, 저장 목록에는 `.tmp`와 `.bak`이 나타나지 않습니다.

백업을 복구하려면 게임을 종료하고, 예를 들어 `QUICKSAVE.sav.bak`을 같은 폴더에 `recovered.sav`라는 새 이름으로 복사한 뒤 불러오세요. 저장 중 오류가 나면 기존 파일을 유지하고 오류를 표시합니다. 헤더·파일 끝 표식 검사는 불완전한 파일을 걸러내기 위한 것으로, 모든 종류의 손상을 검사하지는 않습니다.

기존 한국어 패치에서 만든 저장 파일에 이미 기록된 한국어 문장은 영어로 전환해도 그대로 남을 수 있습니다. 기존 저장 파일을 시험할 때는 복사본을 사용하고 별도 이름으로 저장하세요.

이전 설치본을 정리하면서 보관한 자료가 있는 작업 폴더에는 `build/runtime/preserved/`도 있습니다. 이 폴더에는 기존 세이브·사용자 지도·설정 등이 들어 있으므로 함께 백업합니다. `build/`가 Git에서 제외돼 있어도 **실제 사용자 데이터까지 지워도 되는 것은 아닙니다.**

# 언어별 폰트 지정

[English](fonts.md) · [한국어](fonts-ko.md)

[README로 돌아가기](../README-ko.md) · [현지화 가이드](localization-ko.md) · [개발 가이드](development-ko.md)

## 폰트 바꾸기: 경로 하나와 명령 한 번

개발 환경의 최초 `setup`을 마친 뒤 다음 순서로 진행합니다. 게임은 먼저 종료하세요.

1. 사용할 `.ttf` 또는 `.otf` 파일을 `deps/fonts/`에 넣습니다. Windows에 설치할 필요는 없습니다.
2. 해당 언어의 JSON에 `font` 경로를 지정합니다. 예를 들어 `locales/ko.json`:

```json
{
  "name": "한국어",
  "font": "deps/fonts/MyFont.ttf"
}
```

3. 저장소 루트에서 실행합니다.

```powershell
.\dev.ps1 localize -Python .\.venv\Scripts\python.exe
```

4. `Play.cmd`로 다시 실행합니다. 한국어를 선택한 화면의 한글, 영문, 숫자에 지정한 폰트가 적용됩니다. 메뉴의 강조색과 오류색, 작은 글씨, 일지 글씨도 같은 폰트에서 생성합니다.

상대 경로는 **저장소 루트 기준**입니다. JSON 경로에는 `/`를 쓰면 편합니다. 절대 경로도 허용하지만 다른 개발자와 공유할 설정에는 상대 경로를 권장합니다. 파일이 없거나 지원되지 않는 글꼴이면 오류로 경로를 알려줍니다.

기본 폰트로 돌아가려면 `font` 필드를 지우고 `localize`를 다시 실행하세요. `name`만 있는 언어팩은 최초 `setup --font`로 지정한 Noto Sans KR을 사용합니다. 사용자 폰트의 해시를 `config/dependencies.json`에 등록할 필요는 없습니다.

## 글자가 없는 폰트도 사용할 수 있나요?

각 글자를 다음 순서로 찾습니다.

1. 현재 언어팩의 지정 폰트.
2. 기본 Noto Sans KR.
3. 다른 언어팩의 지정 폰트. 언어 코드 순으로 확인합니다.

예를 들어 영문 전용 폰트를 한국어에 지정하면 영문·숫자는 그 폰트로, 한글은 Noto로 표시합니다. **번역이 빠졌을 때 영어를 표시하는 처리**와 **글리프가 없을 때 다른 폰트로 보완하는 처리**는 독립적으로 동작합니다. 여러 언어 이름과 다른 언어로 저장된 문장을 표시할 수 있도록 모든 등록 카탈로그의 글자를 각 언어용 이미지에 포함합니다.

일반 폰트와 가변 폰트를 지원합니다. 기본 생성 크기는 보통 글씨 16px, 작은 글씨 12px입니다. 가변 폰트에 굵기 축이 있으면 500을 사용 가능한 범위 안에서 적용하고 나머지 축은 기본값을 사용합니다. 기존 UI의 줄 높이에 넘치는 폰트는 자동으로 축소합니다. 글자 간격·공백·정렬·줄바꿈·입력 커서는 생성된 폭을 사용합니다.

현재 범위는 Unicode BMP 문자입니다. 이모지 등 보조 평면 문자, 복잡한 문자 결합·오른쪽에서 왼쪽으로 쓰기, IME 입력 추가는 지원하지 않습니다. 글꼴 모음 `.ttc` 대신 개별 `.ttf`/`.otf` 파일을 사용하세요.

## 미리보기와 오류 확인

| 파일 | 내용 |
| --- | --- |
| `build/runtime/core/locales/ko/preview.png` | 한국어에 적용할 일곱 글꼴 상태 미리보기 |
| `build/runtime/core/locales/fonts-report.json` | 언어별 지정 폰트, 글리프 수, 자동 축소 비율, 보완된 글자의 출처 |
| `build/localization-report.json` | 마지막 `localize` 결과 요약 |

다른 언어의 미리보기는 `ko`를 해당 코드로 바꿔 찾습니다. 최종 모습은 게임에서도 확인하세요. 특히 긴 언어 이름, 숫자, 메뉴, 일지, 입력 커서와 긴 문장의 줄바꿈을 확인합니다.

어느 폰트에도 글자가 없으면 해당 문자, `U+XXXX`, 사용한 번역 키를 출력하며 준비를 중단합니다. 그 문자를 포함하는 폰트를 해당 언어팩에 지정하고 다시 실행하세요. 폰트 생성이 실패하거나 게시 중 교체에 실패하면 기존 정상 언어팩을 유지합니다. 오류를 고치기 전에는 변경한 번역·폰트가 적용되지 않습니다.

## 배포할 파일

번역과 폰트 준비가 성공하면 **`build/runtime/core/locales/` 전체**를 함께 배포합니다. 언어 목록 `languages.dat`, TSV, 언어별 `glyphs.dat`와 BMP 페이지가 한 세트입니다. 플레이어는 Python이나 원본 TTF/OTF, 시스템 폰트 설치 없이 게임에서 언어만 선택하면 됩니다. 이 기능을 포함하는 엔진 빌드가 필요하며 이전 EXE에는 새 언어팩을 설치하지 마세요.

사용한 폰트의 라이선스가 이미지 생성과 배포를 허용하는지 확인하고 필요한 저작권 고지를 함께 포함하세요. `fonts-report.json`에는 개발 PC의 절대 폰트 경로가 기록됩니다. 배포할 때 보고서와 `preview.png`는 제외해도 되지만 `languages.dat`, TSV, `glyphs.dat`, BMP는 유지해야 합니다. 기본 Noto의 고지는 기존 `licenses/`에 있습니다. 사용자 폰트 파일을 저장소에 추가할 때도 해당 폰트의 배포 조건을 따르세요.

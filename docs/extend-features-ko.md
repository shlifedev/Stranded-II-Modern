# 확장판 차이

[English](extend-features.md) · [한국어](extend-features-ko.md)

[README로 돌아가기](../README-ko.md) · [개발 가이드](development-ko.md)

Extended는 향후 별도 게임 규칙·밸런스·콘텐츠를 개발할 에디션으로 유지합니다. 현재 로컬 개발용이며 CI 빌드·배포는 중단되어 있습니다.

다섯 가지 [QOL 기능](qol-ko.md)은 기본판과 공통으로 제공하며 확장판 전용 기능이 아닙니다. 기본값은 **기본판 OFF**, **Extended ON**이고 기존 선택은 보존합니다. 두 판 모두 기존 제작·무게·건축 규칙을 따르며, 현재 확장판에만 추가된 게임플레이·콘텐츠는 없습니다.

실행 파일·버전·리소스·설정·세이브는 별도로 유지하며 두 판 사이에서 데이터를 자동 복사하지 않습니다.

# QOL 설정

[English](qol.md) · [한국어](qol-ko.md)

[README로 돌아가기](../README-ko.md) · [개발 가이드](development-ko.md)

Stranded II와 Extended 모두 **설정 → QOL**에서 아래 기능을 각각 켜고 끌 수 있습니다. 기본값은 **기본판 모두 OFF**, **Extended 모두 ON**이며 저장된 선택이 우선합니다. 적용하면 저장과 동시에 반영되고, 취소하거나 **Esc**를 누르면 아직 적용하지 않은 변경을 버립니다.

| 기능 | 사용 방법 |
| --- | --- |
| 조합법 도감 | 인벤토리에서 도감을 열어 게임에 로드된 조합법을 검색합니다. 분류·제작 가능 여부로 좁히고 재료, 관련 조합법을 확인하거나 한 번 제작할 수 있습니다. 조리 등 별도 상호작용은 안내로 표시합니다. |
| 보관함 빠른 이동 | 보관함·시체를 연 상태에서 Shift+클릭으로 묶음을 이동합니다. 선택한 아이템은 **1**로 1개, **F**로 묶음을 이동합니다. **R**은 모두 수집, **Shift+R**은 보관함에 이미 있는 종류의 아이템을 맡깁니다. 맡기기는 장착·빠른 슬롯 아이템을 보호합니다. |
| 시체 수집 후 닫기 | 빠른 아이템 이동을 켠 상태에서 모두 수집한 뒤 시체가 비었을 때 인벤토리를 자동으로 닫습니다. 일반 보관함은 닫지 않습니다. |
| 자동 정렬 | 표시 순서를 빠른 슬롯 1–9 → 도구 → 무기 → 탄약 → 음식 → 물약 → 재료 → 기타로 정리하고 같은 분류에서는 이름순으로 표시합니다. |
| 건축 연속 입력 | 망치로 건축할 때 우클릭을 누르고 있으면 같은 대상에 재료를 계속 공급합니다. 버튼 해제, 건축 완료, 대상·장비 변경, 메뉴·포커스 전환, 거리 이탈 시 멈춥니다. |

제작 조건, 무게 제한, 건축 재료 비용과 망치 사용 간격은 기존 규칙을 따릅니다. 정렬은 표시 순서만 바꾸며 아이템을 자동으로 이동·삭제하지 않습니다. 기본 게임과 Extended는 설정·세이브를 별도로 사용합니다.

## FPS 표시

두 판 모두 **F2**로 디버그 모드를 켜지 않고 오른쪽 위 FPS 숫자만 켜고 끌 수 있습니다. 실행할 때는 표시가 꺼져 있으며 QOL 설정과 별개로 동작합니다. 전체 디버그 모드의 기존 FPS 표시는 유지합니다.

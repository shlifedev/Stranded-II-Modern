## Stranded II : Modern

[English](README.md) · [한국어](README-ko.md)

Blitz3D 1.118로 다시 빌드한 Stranded II의 비공식 현대화 버전입니다. 원작의 생존·탐험 경험을 유지하면서 높은 프레임과 편리한 화면 전환을 지원합니다.

현재 개발 중이며, 안정판을 준비하고 있습니다.

## 기본판과 확장판

기본판(Classic)은 현재 게임 경험을 유지하며, 확장판(Extended)은 앞으로 별도 UI·QOL·콘텐츠·리밸런싱을 개발할 배포판입니다. 현재는 분리 기반만 구현했으며 두 판의 게임 동작과 콘텐츠는 같습니다.

두 판은 공통 엔진을 사용하지만 실행 폴더·설정·세이브·버전·배포 ZIP이 분리됩니다. 소스 저장소에서 기본판은 `Play.cmd`, 확장판은 `Play-Extended.cmd`로 실행합니다. 확장판은 먼저 `setup --edition extended`와 `build --edition extended`로 준비하세요. 자세한 경계와 명령은 [개발 가이드](docs/development-ko.md#기본판과-확장판)를 참고하세요.

## 수정된 것들

- 기존 게임의 `20ms`(50Hz) 단위 업데이트를 경과 시간에 맞게 보정해, 60/120/144 FPS에서도 게임 속도가 유지되도록 수정했습니다. 기본 목표 프레임은 **144 FPS**입니다.
- 전체 창 모드(테두리 없는 창)를 지원하며, Alt-Tab 후 화면이 깨지는 문제를 수정했습니다.
- 설정에서 해상도·60/120/144 FPS·창 모드를 선택할 수 있습니다. 화면 설정은 재시작하면 적용되며, 모니터 크기에 맞추는 자동 해상도도 제공합니다.
- 빠른 저장·불러오기의 무반응을 수정했습니다. 저장 파일을 안전하게 교체하고 이전 저장본을 백업하며, 자동 저장은 5개를 순환합니다. 메인 메뉴의 **계속하기**로 가장 최근 저장을 불러옵니다.
- **현지화 기반 구현:** 하나의 실행 파일에서 한국어와 영어를 선택할 수 있습니다. 설정 → 그래픽 → 언어에서 변경한 뒤 게임을 다시 실행하면 적용됩니다. 현재 실험 기능입니다. 언어팩과 폰트 파일 경로를 지정해 사용자 번역·글꼴을 추가할 수 있습니다.

## 예정

- 일본어 등 추가 언어의 번역 제공.
- 언어 전환, 기존 저장 파일 호환성, 다양한 화면 환경의 검증을 거쳐 안정판 준비.

## 실행하기

빌드가 준비된 폴더에서는 `Play.cmd`로 실행합니다. 소스만 내려받았다면 [개발 가이드](docs/development-ko.md)에 따라 원본 게임 리소스를 준비하고 빌드하세요.

Windows 10 이상이 필요합니다. 화면 설정과 고해상도 모니터의 렌더링 제한은 [실행 및 설정](docs/playing-ko.md)을 참고하세요.
